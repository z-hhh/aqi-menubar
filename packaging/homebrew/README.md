# A Homebrew tap for this app.
#
# The cask lives in its own repository (a "tap") named
# `z-hhh/homebrew-aqi-menubar`, with this one file under `Casks/`:
#
#   brew install --cask z-hhh/aqi-menubar/aqi-menubar
#
# `bump.sh` rewrites `Casks/aqi-menubar.rb` with a new version and checksum;
# the release workflow runs it after every tagged build, so the tap always
# points at the newest release.

See `SUBMIT.md` for what the official `Homebrew/homebrew-cask` repository
requires before the app can go in without a tap.
